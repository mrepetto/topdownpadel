Play the browser test

The current testing build is available at topdownpadel.com/game/. Mobile store versions are coming soon.

Add to your iPhone home screen

Open the game in Safari, tap Share, then Add to Home Screen. Launch it from that icon for the standalone testing experience. If an older shortcut opens the website, remove that shortcut and add it again from /game/. Removing an icon and clearing browser data are different actions: avoid clearing game data if you want to keep your saves.

Report a problem

Please include your phone model, browser or app mode, what you were doing, and a screenshot or recording if possible. Do not send passwords or private account details.

Contact Korpos Consulting →

Where is my progress?

Progress currently belongs to the browser or home-screen app where you played. Another browser, another device or switching between www and the bare domain can show different saves. Use the same address and browser as before.

Ayuda

Juega a la versión de prueba en /game/. En iPhone, abre esa dirección en Safari y utiliza Compartir → Añadir a la pantalla de inicio. Si un acceso antiguo abre la web, créalo nuevamente desde /game/. Para informar de un error, incluye modelo de teléfono, navegador, pasos para reproducirlo y una captura. El progreso se guarda localmente: utiliza el mismo navegador y dirección donde jugaste.
